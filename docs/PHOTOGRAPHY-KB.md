> 本知识库基于全球公开摄影理论、学术研究与行业实践整理（v1.0，2026-10-17），作为本项目构图算法的设计依据。
> 来源类型：摄影教育社区共识、学术论文（Adobe Research / Penn State / 中科大等）、眼动实证研究。

## 1. 人像裁切解剖学（Cropping Anatomy）

### 1.1 关节禁区（Don't crop at joints）
**共识来源**：SLR Lounge / Envato Tuts+ / Nerdy Photographer / Imagen AI 等多源一致。

| 禁区（禁止裁切线穿过） | 原因 |
|---|---|
| 颈部（cervical） | 视觉断头感 |
| 肩关节 | 截肢感最强区域之一 |
| 肘关节 | "If it bends, don't crop there" |
| 腕关节 / 手指 | 最常见业余错误 |
| 髋关节 | 破坏身体比例 |
| 膝关节 | 下肢截断感 |
| 踝关节 / 脚趾 | 全身像最常见的失误 |

**机理**：裁切线穿过可弯曲关节时，大脑无法自动补全肢体延伸，产生"截肢"错觉（amputation illusion）。

### 1.2 安全裁切带（Tapering points / limb midpoints）
| 安全区 | 说明 |
|---|---|
| 小腿中段 | 全身像下缘推荐位 |
| 大腿中段 | 半身像下缘推荐位 |
| 躯干（胸/腰腹中段） | 半身/特写过渡 |
| 上臂中段 / 前臂中段 | 手臂出画推荐位 |
| 锁骨下方、下颌线上方 | 特写像的自然边界（眼动研究验证） |

**眼动实证**：爱丁堡大学 2021 眼动研究——裁切在自然解剖边界（锁骨下、眉上）的人像，观者注视时长比切关节者**长 37%**。切关节触发潜意识不适（biomechanics + neuroaesthetics）。

### 1.3 头部留白（Headroom）
- 标准：头顶到上边缘 ≈ **一指宽**（thumb's width）
- 过多 → 主体显小；过少 → 幽闭压抑

### 1.4 七大高失败率解剖区
frameandfocal（2026）归纳的量化失败区：关节 ×7 区 + **骨骼中点（mid-bone）**也是雷区（不是只有关节不能切，骨头正中间切同样怪异）——安全带是**节段中点偏关节远端 1/3 处**而非严格几何中点。

## 2. 位置构图（Placement）

### 2.1 三分法与力量点
- 三分线 4 个交点 = 力量点（power points）；人像的**眼睛**放上部交点（眼/鼻梁在三分线上）。
- 水平线对齐横三分线；地平线超过画面 2/3 需有值得看的理由。

### 2.2 视线留白（Lead room / Nose room / Looking space）
- 定义：主体**视线或运动方向前方**保留的空白。
- 原理：观者视线跟随主体视线，前方无空间 = 被墙壁挤压感。
- **量化**：静止人像 lead room ≈ 1/4~1/3 前方空间；运动主体（跑/车）需要更大前方空间；Neil Oseman "光谱理论"——从满留白到零留白是表达光谱（零留白 = 压迫/紧张/负面情绪的可 deliberate 手法）。
- 实现：人脸朝向向量（由关键点：双眼连线 + 鼻尖偏移估算）→ 朝向侧扩边。

### 2.3 黄金分割
- 三分法的精化变体：交点位于 0.382/0.618 而非 0.333/0.667。
- 两者作为可切换的吸附网格（用户偏好）。

## 3. 学术自动裁剪方法综述（Computational Auto-Cropping）

| 方法 | 来源 | 核心思想 | 对本项目的启示 |
|---|---|---|---|
| 三模型组合 | Adobe Research (Fang et al., MM'14) | **视觉构图 + 边界简洁性 + 内容保持** 三分评估 | 裁切评分的三支柱框架 |
| CCR 级联回归 | Guo et al. (TIP'17) | 美学特征提取 → 级联回归**精修**裁剪框（两步法） | "先粗后精"级联设计 |
| 注意力框预测 | Deep Cropping | 模拟人类"先定主体再调框"流程，避免滑窗暴力搜索 | 实时性关键：主体框预测替代滑窗 |
| 构图优化 | Liu et al. (EG'10, 中科大) | 构图准则量化打分 + crop-and-retarget 组合算子优化 | 多目标打分函数设计参考 |
| ProCrop (2025) | JHU/Microsoft | **检索式**：从专业摄影师构图库检索相似场景参考裁切 | 未来方向：专业样例库 |
| Outward Cropping | Zhong et al. (TOG'21) | 向外扩展（生成式补画）突破原图边界 | 远期方向，暂不做 |

**本项目采用**：`主体框预测（检测模型）→ 候选裁切窗生成 → 多准则评分（构图/关节安全/留白/边界简洁/内容保持）→ 级联精修`。全部规则可解释、可调参，不依赖大型美学 CNN（保实时与离线）。

## 4. 光位模式诊断（Lighting Patterns）五分类

| 模式 | 判定特征（阴影/亮区形态） | 情绪 |
|---|---|---|
| **Butterfly 蝶形光** | 鼻下蝶形阴影；光位于正前上方 30-45° | 美妆/优雅，拉长脸型 |
| **Loop 环形光** | 鼻影呈小环状偏向暗侧脸颊；最常用默认 | 安全百搭 |
| **Rembrandt 伦勃朗** | 暗侧脸颊出现**倒三角光斑**（眼下到鼻翼）；90°+ 侧高位 | 戏剧/古典 |
| **Split 分割光** | 鼻影把脸对半分（90° 正侧） | 高对比/硬朗 |
| **Flat 平光** | 几乎无阴影（光贴相机轴） | 平淡（诊断时提示"缺乏立体感"） |

**辅助判定**：catchlight（眼神光）位置指示光源方位；亮暗脸亮度比对数 → 光比；顶光/底光（非常规）通过阴影方向（眼窝阴影向上/下）判定。
**实现路径** `[D]`：人脸关键点把面部分成亮/暗两侧 → 各自亮度统计 → 鼻影位置（鼻尖-鼻翼关键点区域）→ 模式分类器（规则树）。非人脸场景退化为：直方图 + 主光源方向估计（Sobel 梯度/亮区质心）。

## 5. 拍前引导四条（Pre-shot Guidance，本项目定义）

1. **对位引导**：主体框 vs 目标构图框的偏差向量 → 箭头/吸附提示（移近/移远/左右平移）。
2. **水平引导**：陀螺仪 → 水平仪指示（地平线水平 + 垂直线校正）。
3. **留白引导**：视线朝向侧空间不足 → "向左/右移动"提示。
4. **安全引导**：关节禁区即将入裁切线 → "后退一点" / "调整高度"提示。

（四条对应实时取景的四个判定器，输出统一为"方向 + 动作"元组，UI 层渲染箭头/文案。）

## 6. 反规则（何时刻意打破）

- 居中构图：直视镜头的力量型人像（对称张力）。
- 零留白：压迫/紧张/负面情绪表达。
- 切关节：时尚编辑的高概念断裂（Lucian Freud 式）——**默认算法永远不主动输出**，仅手动模式允许。
- 大负空间：孤独/疏离表达。
**算法立场**：规则可解释、可关断；"打破规则"必须是显式用户选择而非算法输出。
