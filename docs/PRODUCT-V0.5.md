## 二、当前 v0.4.1 与目标态差距
- ✅ 已有: B1-B4, B6, D1-D5
- ❌ 核心缺失: **整个 A 组(实时取景引导)** —— 这才是"无脑自动拍照"的灵魂, 现在只是个"拍后裁切器"
- ⚠️ 半成品: B5 光位(算法有了 UI 没接), C 组全缺
- ❌ D6 流程债: 本喵连续两轮未自测即推送, 导致 cropH/cropIt 连环炸

## 三、v0.5 实现顺序(按用户价值排)
1. **A1+A2 相机实时取景+主体框** —— 打开即相机, 实时框人
2. **A3+A4 距离建议+圆环对齐** —— 无脑引导的核心体验
3. **A7 快门自动优化裁切** —— 拍完直接出成片(替代现在的手动上传流程)
4. B5 光位接回 + 讲解文案丰富
5. C1+C2 滤镜推荐(开源 LUT)
6. C3 偏好学习
7. D6 自动化: Playwright 本地冒烟测试脚本(截图验证渲染非空白)后才允许 push

## 四、每步验收方式(强制)
- 本地 Playwright 打开页面 → 截图 → 检查关键 DOM 存在 + canvas 非空白 → 才提交
- 手机实测由洋洋执行, 反馈问题 24h 内修复
