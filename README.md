# AI Composition Tool Beta

移动端 AI 实时构图工具 · 原创开源实现。

> 本项目基于多轮公开资料学习研究与开源视觉模型选型，从零构建的一套移动端 AI 实时构图工具。

## 功能矩阵（规划）

| 能力 | 说明 |
|---|---|
| 智能人像裁切 | 人像保护式构图裁切，避免切头/手脚/关节 |
| 宽幅横拍 | 16:9 横幅构图建议与裁切 |
| 视线留白 | 人像视线方向留白（nose room）优化 |
| 边缘吸附 | 主体构图线边缘吸附（edgeSnap） |
| 背景保护 | 裁切时背景主体范围保护（RoD） |
| 拍前引导 | 构图对位实时引导 |
| 光位诊断 | 四类光位识别 + 综合曝光诊断 |
| 滤镜推荐 | 基于场景的滤镜自动推荐 |
| 可训练偏好 | 用户偏好学习，个性化推荐 |
| 离线可用 | 本地视觉模型推理，无网可用 |
| 永久免费 | 不限次数 |

## 架构

- 本地推理：开源视觉检测模型（HuggingFace 托管）
- 云端增强：自建云端调用链路（可切换）
- 展示层：移动优先 Web / GitHub Pages
